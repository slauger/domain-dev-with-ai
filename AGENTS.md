# Hinweise für Coding-Agenten

Dieses Repository enthält eine generische Schulung (Text, Vorlagen, Folien). Es gehört zu keinem bestimmten Produkt.

## Regeln

- Generisch bleiben: keine Namen realer Produkte, Projekte, Kunden, Organisationen, Hosts oder Personen. Beispiele nutzen erfundene Software und erfundene Personen (z. B. Peter, Softwarearchitekt; Karl, Feuerwehrmann).
- Sprache Deutsch, einfach und direkt, für Nicht-Programmierer. Fachbegriffe beim ersten Auftreten kurz erklären.
- Kein Markdown line wrapping: jeder Absatz ist eine einzelne Zeile.
- Nur ASCII-Interpunktion: keine Gedankenstriche (Em-Dash, En-Dash), keine typografischen Anführungszeichen, kein Ellipsis-Zeichen. Echte Umlaute und ß verwenden (nicht ae, oe, ue, ss).
- Aussagen über Werkzeuge (Funktionen, Preise, Pläne) mit Quelle und Stand-Datum versehen, weil sie sich schnell ändern.
- Conventional Commits verwenden.
- Folien folgen den Presentation-Standards (Slidev, ein Deck pro Ordner `slides/JJJJ-MM-TT-thema/`).
